An invented passport spread for the Republic of Caldara — a volcanic island nation in the South Atlantic that does not exist. The data page shows Elena Maris Vargas of San Telmo, with a portrait, a machine-readable zone, and issue details; the visa page carries a Portugal visitor visa and a travel history stamped through Lisbon, Cape Town, Rio de Janeiro and Buenos Aires, plus the island's own rule: no private motor vehicles, the island is crossed on foot, by mule, or by the San Telmo funicular.

## Run it

```sh
node main.ts
```

`render.py` draws the spread with Pillow (deterministic, no network); `main.ts` copies the committed `entry.png` to `/output/entry.png`.
